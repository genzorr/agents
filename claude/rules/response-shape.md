# Response Shape

`conciseness.md` governs response content and writing discipline; this rule governs output organization.

- Lead with the conclusion, recommendation, or finding.
- Organize each response around the reader's next decision or action.
- Use blank-line-separated blocks; use headings, lists, tables, or code fences when they improve scanning.
- Match depth to the request: concise for direct questions, thorough for walkthroughs, reviews, plans, and "why" questions.
- When the user requests a standalone artifact, keep commentary outside the artifact unless context is necessary.
- Follow a task-specific skill's output contract when one exists.
