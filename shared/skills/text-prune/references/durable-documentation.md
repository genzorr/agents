# Durable Documentation Mode

Preserve source authority, current contracts, identifiers, headings and anchors with inbound callers, exact links, tables, code blocks, provenance, intentionally historical records, and unresolved questions. Remove obsolete status only when a current authority or durable replacement supports removal; age, silence, or apparent inconsistency alone is insufficient.

Before deleting, renaming, or rewording content, inspect inbound consumers: exact-phrase and source-shape assertions, import or include directives, files citing a heading or anchor, catalog and traveling-reference declarations, generated-file contracts, and relevant validators. Do not re-wrap or unwrap untouched prose.

When an authorized change requires a paired consumer update, keep that consumer in scope, verify the protected consequence, and name it in the ledger. Preserve unresolved or stale-but-unproven material as `FLAG` until the owning authority resolves it.
