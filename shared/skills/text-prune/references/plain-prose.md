# Plain Prose Mode

Preserve the author's intent, factual claims, requested tone, qualifications that change meaning, and transitions needed to follow the argument. Remove repeated meaning, filler, throat-clearing, redundant examples, and excess framing.

Do not flatten deliberate emphasis into accidental ambiguity. Treat repetition as removable only when every occurrence serves the same audience and function; a repeated constraint at the point of action may be operative rather than redundant. Return a no-op when the text is already appropriately compact.
