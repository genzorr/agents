# Answer Pro

Accept pasted response text and supplied files, directories or ZIPs. Inspect relevant deliverables, including a report and requested artifacts, and identify referenced or requested outputs that are missing. Inspect archives safely using existing tools or the standard library; avoid extracting paths outside the chosen destination or following unsafe links. Recover the outgoing prompt, user steering before and after it, intended outcome, evidence versions and relevant project context when available. Do not invent submission, receipt or scope; when context is incomplete, state the limit and make the bounded assessment the evidence supports.

Compare the actual answer with the intended questions and outcome and relevant current primary project evidence. Check load-bearing claims and citations proportionally, distinguishing sources cited from those actually inspected, factual support from relevance or necessity, and old snapshots from current state. Identify what is answered, partial, unsupported, contradicted, stale or unresolved, including material missing deliverables. Explain project-specific implications and what to adopt, challenge, defer or reject, with tradeoffs and next actions where useful. Preserve provenance, material contrary evidence and uncertainty; a no-decision result is valid. Do not turn this into a full-repository audit or mandatory findings file.

Pro supplies advice and evidence, not user authority. Preserve selected directions, baseline and method semantics, essential components and requested scope unless the user reopens them or has delegated the choice. Classify a proposed pivot as a proposal, even when its factual premise is supported. Discuss undecided choices; apply project, documentation or code changes only when the existing mandate authorizes them. Do not implement or pivot merely because a report recommends it.

For experiments distinguish coherent-strategy utility, interactions and component attribution. A package result cannot establish component causation; evaluating a strategy need not wait for isolated attribution. Scope prerequisites and deferrals to the particular treatment, action or claim they support.
