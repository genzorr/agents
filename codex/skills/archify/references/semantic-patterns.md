# Semantic patterns

Use these as conditional routing aids, not as new diagram types. Fan-in queue or bottleneck triggers when several producers contend for one consumer; preserve producers, queue, consumer, wait/retry edge, and capacity signal; budget 8 nodes and 12 edges; route to workflow with a static bottleneck node fallback. Untrusted input to durable artifact triggers when data crosses validation, policy, or persistence boundaries; preserve source, trust boundary, filter, artifact, and rejected path; budget 10 nodes and 14 flows; route to dataflow with a static input-to-artifact chain fallback. Paired policy evaluation triggers when one request is checked by two related policy decisions; preserve request, both evaluators, decision join, and deny path; budget 9 nodes and 12 edges; route to workflow or sequence with a static two-check table fallback. Secure paved road or trust boundary triggers when approved and unapproved paths must be distinguished; preserve actors, boundary, approved route, and blocked route; budget 10 nodes and 14 edges; route to architecture with a static boundary-plus-arrows fallback. Governance or control catalog triggers when controls map to owners or evidence; preserve control, owner, evidence, and gap relationships; budget 12 nodes and 16 edges; route to architecture with a static control matrix fallback. Compensating security layers triggers when multiple controls reduce one threat across stages; preserve threat, each control layer, residual risk, and ordering; budget 12 nodes and 16 edges; route to architecture with a static layered-stack fallback. Preserve the semantic primitives that triggered the pattern and disclose any compression.

Before rendering, state or infer the audience, destination, detail level, and nearest existing type. Keep the diagram static by default; use trace animation only when requested and when reduced-motion, print, and static capture retain the complete meaning.
